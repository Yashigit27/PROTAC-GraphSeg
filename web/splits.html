Exam design

Five splits that test different kinds of generalization.

Random accuracy alone is not enough. These exams separate “recipes already known” from “chemistry the model never studied.”

Standard

random

Shuffle molecules into 80/10/10. Everyday performance benchmark.

Best for: sanity check / upper baseline comfort
Hard

unseen_warhead

Hold out rare warhead families from train. Closed-book dictionary should collapse.

Best for: proving lookup ≠ understanding
Hard

unseen_e3

Hold out rare E3 families. Same fairness logic as unseen warhead.

Best for: E3 novelty stress test
OOD

fingerprint_ood

Keep molecules least similar (Morgan / Tanimoto) to a study pool.

Best for: chemical neighborhood shift
Time-like

newer_chemotype

Sort by Compound ID and test on newer entries. Mimics “train on past database, test on future designs.”

Best for: deployment-style drift conversations
Skill tip: when you present results, always say which split. “0.95 accuracy” without the exam name is not scientifically meaningful.
