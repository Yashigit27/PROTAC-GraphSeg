Three solvers, one task

Baselines support the claim. The GNN is the claim.

All methods output atom-level W / L / E3 labels. Only the GNN is positioned as the primary research model.

Baseline A · Ribes-inspired

Dictionary matching

Look up warhead and E3 recipes, paint matched atoms, leftover = linker.

  • No learning from train seats
  • Fair mode: train-only recipe book
  • Fails when the recipe is missing (unseen splits)
  • Still useful as teacher for weak labels in notebook 01
Baseline B · Lab Mate-inspired

XGBoost bond cutting

Score every bond as cut / not-cut, take top-2 cuts, convert fragments to labels.

  • Uses local bond features + Morgan context
  • Train-only SVD (no test leakage)
  • Atom score allows W↔E3 swap
  • Works without dictionary recipes, weaker on newer IDs
Main model · Yashi contribution

Graph Neural Network segmentation

Molecular graph → shared GIN encoder → atom head (W/L/E3) + bond boundary head, trained with smoothness and soft reconstruction so predictions stay chemically consistent.

Why it is differentiated

  • Learns representations instead of hand-built cut rules
  • Does not need the recipe book at inference
  • Soft reconstruction encourages valid 3-part splits
  • Optional AttrMask pretraining vs training from scratch
  • Evaluated on the same five hard splits as baselines
