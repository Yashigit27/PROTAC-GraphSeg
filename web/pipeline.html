From database to decision

How the Yashi pipeline runs.

Each major step maps to one notebook. This page is the process view — not a marketing funnel.

01 · Data & weak labels

Load PROTAC-DB, build warhead/E3 recipe books, match atoms, keep only labels that reassemble into 3 fragments, create five splits, export graphs.

labeled_protacs.jsonl · splits.pkl · refs.pkl

02 · Baselines

Score dictionary (train-only book) and XGBoost bond-cut models on every split. Establishes fair classical competitors.

baselines_metrics.json

03 · Train GNN (main method)

AttrMask pretrain optional, then fine-tune GIN with atom/bond heads plus soft reconstruction. This is the core scientific contribution.

scratch + pretrained checkpoints

04 · Evaluation

Same metrics for everyone: atom accuracy, exact-3 fragments, reassembly. Build the final comparison table.

final_results.json

05 · Inference demo

Paint W/L/E3 on example molecules for qualitative inspection.

notebook demo · this web workbench
